# Start here

If you or someone close to you was told recently that this is epilepsy, you probably have more
questions than anyone has had time to answer. Pick the path that fits and work through it at
your own pace. Nothing here is urgent reading. If something is happening right now, go to
[what to do during a seizure](../now/index.md).

## If you are not sure where to start

Three things help almost everyone, in this order.

1. Write down what happened. What you or the witness saw, how long it lasted, and what
   happened afterwards. The description matters more to a neurologist than any test.
2. Learn seizure first aid and teach one other person. [Seizure first aid](../chapters/02-seizure-first-aid/index.md).
3. Book the appointment you are owed. If you do not have a neurologist yet, ask your primary
   care clinic for a referral, and see [how far the nearest specialist is](../initiatives/care-access.md).
